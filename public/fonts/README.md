# Arabic Font Asset

- **Font Family**: Noto Sans Arabic (Variable)
- **File**: `NotoSansArabic-Variable.woff2`
- **Source**: [Google Fonts - Noto Sans Arabic](https://github.com/google/fonts/tree/main/ofl/notosansarabic)
- **License**: SIL Open Font License, Version 1.1 (OFL)
- **Usage**: Self-hosted variable font providing weight range (100–900) for high-fidelity Arabic typography across modern browsers. System fallbacks (`system-ui`, `Segoe UI`, `Tahoma`, `Arial`, `sans-serif`) are retained for compatibility.
